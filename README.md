
# Advanced Phishing URL Detection System

## Project Overview
This project aims to detect potentially malicious phishing URLs using URL analysis and machine learning.

## Objectives
- Analyse URL characteristics.
- Identify potentially suspicious URLs.
- Train a machine learning model to classify URLs.
- Display detection results and risk explanations.

## Technologies
- Python
- Scikit-learn
- Pandas
- Flask
- Git and GitHub
